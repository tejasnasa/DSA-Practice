## Prerequisites

- C++ compiler with C++17 support (`g++` recommended)

## Compile and Run

From `/home/runner/work/dsa-practice/dsa-practice/C++`:

```bash
g++ -std=c++17 -o program path/to/file.cpp
./program < input.txt > output.txt
```

You can also compile and run any file directly:

```bash
g++ -std=c++17 -o program path/to/file.cpp
./program
```
